# Book Distribution - HKM Vizag Android Wrapper

This folder contains a native Android wrapper app for the Gambhiram public request flow.

## What it does

- Opens the live KKD sales page:
  - `https://book-distribution-erp.vercel.app/request?warehouse=WH001`
- Supports:
  - login to the Gambhiram request page
  - live stock browsing
  - direct sale entry posting
  - app-style wrapper experience

## Android Studio setup

1. Open Android Studio
2. Choose **Open**
3. Select the folder:
   - `android-wrapper-vizag-request`
4. Let Gradle sync
5. Build and run on the Android phone

## Important notes

- This wrapper is intentionally plain.
- Printing is handled only in the separate Matchless app.
