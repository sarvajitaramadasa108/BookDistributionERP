# Srila Prabhupada Book Distribution Android Wrapper

This folder contains a native Android wrapper app for the Test Distribution PWA flow.

## What it does

- Opens the live distribution page:
  - `https://book-distribution-erp.vercel.app/testdistribution`
- Supports:
  - requester details lookup by mobile number
  - book and devotional item requests
  - returns
  - stock tracking
  - sale entry
  - reports
  - app-style wrapper experience

## Android Studio setup

1. Open Android Studio
2. Choose **Open**
3. Select the folder:
   - `android-wrapper-book-distribution`
4. Let Gradle sync
5. Build and run on the Android phone
