# Kakinada Warehouse Android Wrapper

This folder contains a native Android wrapper app for the Kakinada plain sales-entry flow.

## What it does

- Opens the live KKD sales page:
  - `https://book-distribution-erp.vercel.app/stallsales`
- Supports:
  - login to the Kakinada sales page
  - live stock browsing
  - direct sale entry posting
  - app-style wrapper experience

## Android Studio setup

1. Open Android Studio
2. Choose **Open**
3. Select the folder:
   - `android-wrapper-kakinada`
4. Let Gradle sync
5. Build and run on the Android phone

## Important notes

- This wrapper is intentionally plain.
- Printing is handled only in the separate Matchless app.
